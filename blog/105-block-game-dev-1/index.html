Block Game Dev #1

            #tech #life
          

          
Game development is pretty fun. I've been working on a couple games for the better part of a year now. I don't really want to speak on the end goal; rather I'd like to learn how to communicate better in technical stuff through this blog and my development!


I've begun to work on the LoD after getting 400fps at 32k~ chunks rendered (64x64x12x2 chunks, y,up,down). I am hoping to keep the same efficiency in the LoD system which is designed to extend the view distance so the world looks infinite. It will form a sort of Fog of War around explored vs un-explored chunks.


The noise system is fun too; I had made it interchangeable from cpu/gpu at runtime so older systems can benefit from GPU noise without having to rely on CPU SIMD which may not exist!
